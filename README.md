# Weihnachtsferien-Countdown Android-App 🎄

Dieses Repository enthält den Android-App-Build für den Weihnachtsferien-Countdown.

## APK herunterladen

Nach erfolgreichem GitHub-Actions-Build: **Actions → Build Weihnachtsferien Countdown APK → Artifacts → WeihnachtsferienCountdown-APK**.

Die APK wird als Debug-APK für Tests bereitgestellt. Der Quellcode liegt im Projektarchiv `WeihnachtsferienCountdown-Android-Projekt.zip`.
